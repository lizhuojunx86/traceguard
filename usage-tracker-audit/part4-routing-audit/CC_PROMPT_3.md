## Task 1 — 给冻结副本配一份说明，不要重新拷

`traces_routing_audit.2026-07-04-audit.db` 的 `routing_decisions` 忠实保存了
§3，这是它的用途，没问题。但它的 `traces.cost_usd` 里，opus-5 那 5,992 条是
**round-1 回填的偏低值 $1,127.77**，不是修正后的 $1,213.91，也不是 07-04 发布
当时的 NULL。

所以这个副本既不是「07-04 发布态」，也不是「当前正确态」，它是
**「重新生成之前的最后一个状态」**——那正是它需要成为的东西，但名字没说出来。

不要重拷（重拷会把它变成一个 post-fix 产物，就失去意义了）。在它旁边写一个
`traces_routing_audit.2026-07-04-audit.README.md`，讲清三件事：

1. 拷贝时间 2026-08-08 12:02，用途：保住 `report_en.md` §3 的可复算性。
2. `routing_decisions` = 425 / 96 / $1,248.1327，逐位复现 §3。**这是它保证的。**
3. `traces.cost_usd` 里 opus-5 含 round-1 的偏低值。**从这个副本重算成本会得到
   错的 opus-5 数字。** 它保证的是决策表，不是 trace 成本。

一个文件说清楚它保证什么、不保证什么，比一个看起来很权威的文件名安全。
